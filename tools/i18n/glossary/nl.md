# Loft Dutch (nl) glossary

Address: *je/jij* (lower case, informal, as current Apple, Google and Microsoft Dutch UI); *jouw* only for stress
("*jouw* gateway" where the English stresses *your*). Sentence case in UI text.

Button and menu verbs follow each platform's Dutch convention:
- Apple (Mac, iPhone): imperative, as Apple's own Dutch UI ("Annuleer", "Ga door", "Plak", "Koppel", "Bewaar",
  "Log in", "Log uit", "Maak aan", "Gereed").
- Android and Windows: infinitive, as Google and Microsoft Dutch UI ("Annuleren", "Doorgaan", "Koppelen",
  "Opslaan", "Inloggen", "Uitloggen", "Maken").
- Labels that read as a name or heading use the infinitive on every platform ("Handmatig instellen").

Typography: “…” double curly quotes (‘…’ inside), one-character ellipsis "…" directly after the word, no space
("Handmatig instellen…", as Apple/Microsoft NL). No capital after a colon unless a name or a full new sentence
in quotes follows (the Norwegian capital rule does not apply). "pc" lower case (Taalunie and Microsoft NL).
Compounds with a name take a hyphen: Loft-gateway, Loft-map, Loft-app, NAS-account, SMB-versleuteling.

## Tagline and headlines

- "Not the cloud. The loft." = "Niet in de cloud. Op zolder." Dutch says "de cloud"; the attic is "zolder"
  ("op zolder" is where you keep things). Dutch "loft" means an open-plan apartment, not an attic, so the
  name-play cannot survive; the contrast cloud/attic does.
- "Your files, kept at home." = "Je bestanden, thuis bewaard."
- "Both treasury and best parlour." = "Zowel schatkamer als pronkkamer."
